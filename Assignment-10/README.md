# Assignment 10: SQL String & Pattern Matching

**Course:** TuteDude Data Analytics | **Status:** Approved

* **Task 1:** Created and populated the `Employees` table with sample text records containing names, departments, and email addresses.
* **Task 2a:** Filtered employees whose email addresses belong to the 'example.com' domain using pattern matching (`LIKE '%@example.com'`).
* **Task 2b:** Queried employees whose names start with the letter 'A' (`LIKE 'A%'`).
* **Task 2c:** Retrieved employees whose names end with 'son' (`LIKE '%son'`).
* **Task 2d:** Extracted employees whose name has 'v' as the second character using string substring functions.
* **Task 2e:** Selected employees belonging to departments containing the substring 'IT'.
* **Task 2f:** Performed case-insensitive searching to find employees in 'hr' departments using `LOWER()`.
